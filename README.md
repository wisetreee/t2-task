# Кормим кота — тестовое задание от Т2

Приложение для выбора и покупки «кормов» для кота с карточками и интерактивным наведением.

[Демо на Vercel](https://t2-task-eta.vercel.app/)

---

## 🚀 Установка и запуск локально

1. Клонируйте репозиторий:

```bash
git clone https://github.com/your-username/your-repo.git
cd your-repo
```
2. Установите зависимости:

```bash
npm install
```
3. Запустите приложение:

```bash
npm run dev
```
